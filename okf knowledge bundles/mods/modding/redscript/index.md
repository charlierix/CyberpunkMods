# Redscript Patterns

Concept files documenting Redscript code patterns observed across the mod corpus.

| Concept | Description |
|---------|-------------|
| [Wrap Method](wrap-method.md) | `@wrapMethod` for intercepting and augmenting native class methods |
| [Replace Method](replace-method.md) | `@replaceMethod` for fully overriding native method implementations |
| [Add Method](add-method.md) | `@addField` / `@addMethod` for extending native classes with new fields and methods |
| [Codeware Framework](codeware-framework.md) | Codeware UI and localization framework integration patterns |
