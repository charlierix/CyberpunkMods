# Modding Infrastructure

Directory listing for modding infrastructure patterns and reusable frameworks used across Cyberpunk 2077 mods. These concepts cover non-game-mechanic patterns — UI rendering, data handling, runtime APIs, code injection techniques, and utility patterns.

## Subdirectories

* [ImGui Patterns](imgui/index.md) — Dear ImGui immediate-mode UI rendering patterns used by 423+ CET mods
* [Data & Utility Patterns](data/index.md) — SQLite, file I/O, JSON serialization, and config persistence patterns
* [CET Runtime Patterns](cet-runtime/index.md) — Observe(), GetSingleton, cron/timers, and vector math patterns
* [Redscript Patterns](redscript/index.md) — @wrapMethod, @replaceMethod, @add, and Codeware framework patterns
* [Lua Utility Patterns](lua-utils/index.md) — OOP/metatables, error handling, string operations, and math interpolation
* [Modding Frameworks](frameworks/index.md) — AMM, Virtual Atelier, Cyberscript, and TweakXL framework integrations
