# Cyberpunk 2077 Mods — Game Mechanic Manipulation Patterns

Knowledge bundle documenting **game mechanic manipulation patterns** used by Cyberpunk 2077 mods. Concepts describe techniques, not individual mods — mods appear as file references within concept files.

## Categories

* [Combat](./combat/index.md) — Damage, weapons, loot, quickhacks, and scanning manipulation patterns
* [Economy](./economy/index.md) — Vendor systems, market pricing, and archive asset injection patterns
* [Media](./media/index.md) — Audio system and localization manipulation patterns
* [Player](./player/index.md) — Player progression, inventory, equipment, saves, and teleportation patterns
* [Systems](./systems/index.md) — Core game system manipulation patterns (callbacks, blackboards, stats, etc.)
* [UI](./ui/index.md) — Camera, HUD, input, photo mode, and settings manipulation patterns
* [World](./world/index.md) — Apartments, crowd, traffic, NPCs, vehicles, weather, and mappins patterns
* [Modding Infrastructure](./modding/index.md) — ImGui UI rendering, data persistence, SQLite, file I/O, and utility patterns — Apartments, crowd, traffic, NPCs, vehicles, weather, and mappins patterns
