# Drop Point Modifications

Modifying DropPointsReimagined.* TweakDB records to alter drop point mechanics.

Mods modify `DropPointsReimagined.*` TweakDB records to change drop point rewards, availability, or mechanics. This is part of the Drop Points Reimagined framework for customizing the drop point system.
